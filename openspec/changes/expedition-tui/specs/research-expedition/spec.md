# expedition-tui — Delta Specs (research-expedition)

## ADDED Requirements

### Requirement: Вердикты вопросов в виджете карты

Когда у активной кампании экспедиции есть закрытые вопросы, виджет карты (существующее требование «Виджет карты») SHALL дополнить футер строкой вердиктов `Q: <глиф><id>…` в порядке вопросов брифа: `✓` confirmed, `✗` rejected, `❓` inconclusive, `⏳` waiting_for_data, `*` прочий вердикт; закрытый вопрос без вердикта — без глифа. Строка не заменяет счётчик `Q n/m` из существующего футера. При отсутствии закрытых вопросов строка не рендерится. Источник — log.jsonl и brief.json кампании; fail-soft: недоступный лог исключает строку, но не карту.

#### Scenario: Есть закрытые вопросы
- **WHEN** кампания имеет ≥1 закрытый вопрос с вердиктом
- **THEN** футер виджета содержит строку `Q:` с глифами и идентификаторами в порядке брифа рядом с существующим счётчиком

#### Scenario: Нет закрытых вопросов
- **WHEN** все вопросы кампании открыты
- **THEN** строка `Q:` не рендерится; остальной футер без изменений

#### Scenario: Неизвестный вердикт
- **WHEN** вердикт закрытого вопроса не входит в стандартный набор
- **THEN** рисуется глиф `*`; рендер не падает
