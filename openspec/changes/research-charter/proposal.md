# Proposal: research-charter

## Why

Сейчас каждая исследовательская кампания требует отдельного подтверждения брифа владельцем (диалог `ctx.ui.confirm`), а вопросы фиксированы брифом. Поэтому агент не может сам продолжить исследование: после отчёта кампании он не запускает следующую, даже когда находки ведут к новым вопросам. Владелец хочет, чтобы агент итеративно проводил исследования: из находок одной кампании строил бриф следующей и так далее, без подтверждения на каждом шаге, но в пределах заранее согласованных рамок.

## What Changes

- Владелец один раз подтверждает **хартию исследования** — файл с лимитами цепочки и правилами автоподтверждения. Ожидаемый хеш хартии задаётся владельцем (диалог или аргумент запуска), модель его не передаёт.
- Агент в цепочке закрывает кампанию (`stop`, `report`), затем пишет бриф следующей кампании из находок предыдущей. Бриф подтверждается автоматически, если проходит проверку хартии: лимиты, неизменность блока ограничений, вердиктов и `evidence_gate`, вопросы опираются на находки цепочки.
- Цепочка ведёт журнал решений (`chain.json`, append-only). Она останавливается по лимиту, по стоп-правилу хартии, по отзыву хартии владельцем или по команде владельца.
- Режим исследования остаётся включённым между кампаниями цепочки и выключается по отчёту последней кампании.
- Headless-обёртка `scripts/research-rpc.mjs` принимает ожидаемый хеш хартии вместо хеша каждого брифа.

## Out of Scope

- Автоматическое подтверждение без хартии (всё по-прежнему требует владельца).
- Изменение вердиктов, правил закрытия и `evidence_gate` внутри цепочки.
- Временной и бюджетный лимит по токенам (по-прежнему не вводится, как в `research-vectors`).
- Параллельные кампании: цепочка по-прежнему одна активная кампания за раз.
- Обзор направлений и типы активности — это `research-map`, не этот change.
- Защита от агента, который пишет произвольные файлы через shell: это остаточный риск, как и для `research-vectors`; защита опирается на хеш из аргументов запуска.

## Capabilities

### New Capabilities
- `research-charter`: хартия владельца, автоподтверждение брифов цепочки, журнал цепочки, лимиты и остановка.

### Modified Capabilities
- `research-vectors`: выход из режима по отчёту становится выходом по отчёту последней кампании цепочки; промежуточный отчёт режим не выключает. Остальные требования без изменений.

## Impact

- `extensions/pi-autoresearch/` — новый модуль хартии и журнала цепочки; `research_brief` получает проверку хартии для брифов цепочки; отчёт учитывает цепочку.
- `scripts/research-rpc.mjs` — аргумент `--charter` и `--approve-charter-sha`.
- `docs/research-vectors.md` — раздел про цепочку (после реализации).
- Совместимость: кампании без хартии работают как раньше.
