# Spec Delta

## MODIFIED Requirements

### Requirement: Маршрутизация по темам
Loop-промпт и нуджи SHALL определять для каждой темы маршрут следующего действия: `behavior` — обычная гипотеза через `propose_hypothesis` с необязательной явной связью с находкой; `measurement` — процедура measurement-трека (`log_measurement_change`); `capability` — билет в `ideas/` с пометкой owner-input; `tradeoff` — вопрос владельцу о предпочтении либо вторичная метрика.

#### Scenario: behavior-находка порождает гипотезу
- **WHEN** открыта behavior-находка и агент предлагает следующую гипотезу на её основе
- **THEN** инструкции предлагают указать id этой находки как явное основание гипотезы, не делая связь обязательной

#### Scenario: capability-находка не порождает прогона
- **WHEN** открыта capability-находка
- **THEN** агент не создаёт гипотезу на её основе; находка уходит в `ideas/` и попадает в отчёт кампании как owner-input gate
